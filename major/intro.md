# 🎯 数智管理是什么

> 你选了一个很新、很酷的专业！

---

## 📖 专业全称

**数智管理** = 数字化 + 智能化 + 管理学

所属学院：**管理学院**（花溪校区）

简单来说：**用数据和 AI 来解决管理问题。**

## 🤔 和传统管理学的区别

| | 传统管理学 | 数智管理 |
|------|----------|----------|
| 决策依据 | 经验 + 直觉 | 数据 + 算法 |
| 工具 | Excel / PPT | Python / SQL / AI 工具 |
| 解决问题 | 定性分析为主 | 定性与定量结合 |
| 毕业去向 | 行政、HR、市场 | 数据分析、数字化咨询、产品运营 |

## 🆚 和其他专业的区别

| 专业 | 偏重 |
|------|------|
| 计算机科学 | 造轮子（开发 AI） |
| 数据科学 | 挖数据（建模分析） |
| **数智管理** | **用工具（业务应用）** |
| 传统管理 | 管人管事（远离技术） |

> 💡 你不是去造 AI 的，而是**用 AI 帮企业解决问题**的人——这恰恰是市场上最缺的！

---

## 🏆 这个专业的优势

1. **交叉学科背景** — 既懂业务又懂技术，复合型人才
2. **实操性强** — 不是纸上谈兵，是真刀真枪用工具
3. **方向新** — AI 浪潮刚起来，人才缺口大
4. **有教改班** — 选拔进入可获得更优质资源
5. **灵活性高** — 可以去企业，也可以去体制内（数字化政务方向）
