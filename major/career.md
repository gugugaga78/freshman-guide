# 💼 就业与发展

> 数智管理毕业能干嘛？路比你想的宽～

---

## 🛤️ 四大方向

```text
              ┌─→ 企业数字化方向 ─→ 产品经理、数字化咨询
              │
数智管理 ──┼─→ 数据分析方向    ─→ 商业分析师、BI 工程师
              │
              ├─→ AI 应用方向     ─→ AI 产品运营、Prompt 工程师
              │
              └─→ 体制内方向     ─→ 选调生、数字化政务
```

---

## 🏢 企业方向

| 岗位 | 做什么 | 需要什么技能 |
|------|--------|-------------|
| 产品经理 | 设计产品、对接需求 | 逻辑、沟通、文档 |
| 商业分析师 | 用数据支撑决策 | SQL、Excel、PPT |
| 数字化咨询 | 帮传统企业转型 | 行业认知、方案能力 |
| AI 产品运营 | 大模型产品落地 | 懂 AI、懂用户 |
| 数据分析师 | 做报表、找洞察 | Python、SQL、BI 工具 |

---

## 🏛️ 体制内方向

| 途径 | 说明 |
|------|------|
| 选调生 | 应届生专属，竞争激烈但起点高 |
| 公务员考试 | 国考/省考 |
| 事业单位 | 相对稳定 |
| 国企 | 稳定 + 待遇不错 |

> 💡 数字化政务是未来趋势，数智管理专业的背景在这里有优势～

## 📈 大学四年规划建议

| 年级 | 重点 |
|------|------|
| 大一 | 适应大学生活，打基础，通过四六级 |
| 大二 | 学 Python/SQL，参加项目/比赛，考证书 |
| 大三 | 找实习！实习是就业最好的敲门砖 |
| 大四 | 秋招/考研/考公，全力冲刺 |
