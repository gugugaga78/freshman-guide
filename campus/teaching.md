## 🚇 地铁直达！

**18号线「重庆理工大学」站** 直达学校 1 号正门，横穿校园就能到宿舍区。报到坐地铁最方便～

## 🚗 花溪校区校门指南（打车必看）

| 校门 | 用途 |
|------|------|
| **1号门（正门）** | 地铁18号线出站直达 |
| **3号门** | 报到主入口（林荫大道）、快递站、离棠轩近 |
| **中门** | 菊轩、竹轩打车到这里最近 |
| **后门** | 离部分宿舍近 |
| ⚠️ 2号门 | **避坑**：门口是超大坡，拖着行李走会累死（有学长被坑过！） |

> 💡 打车前先确认自己宿舍是哪个「轩」，选就近校门，别信"2号门最近"的说法

| 接待站 | 位置 |
|--------|------|
| 重庆北站 | 北广场 + 南广场 |
| 重庆西站 | - |
| 重庆东站 | - |
| 沙坪坝站 | - |
