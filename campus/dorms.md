# 🛏️ 宿舍指南

> 你未来四年的小窝，提前了解一下～

---

## 📍 花溪校区

数智管理专业大一在**花溪校区**（巴南区红光大道69号）。

---

## 🏠 宿舍楼名称（花溪校区）

宿舍楼以「轩」命名，共十栋：

```
棠轩 · 柳轩 · 桂轩 · 柏轩 · 榕轩
荷轩 · 松轩 · 兰轩 · 菊轩 · 竹轩
```

- **棠轩**：最新宿舍，条件最好（"只有十分之一的人能住"），离 3 号门近
- **桂轩**：设施可免费报修
- 菊轩、竹轩离中门近；打车建议按宿舍楼选就近校门

## 🏠 宿舍配置（整合小红书/抖音学长学姐真实经验）

### 基本设施

| 项目 | 详情 |
|------|------|
| **床尺寸** | **90cm × 190cm**（买床垫/床帘按这个尺寸） |
| **房型** | 四人间，上床下桌 |
| **空调** | ✅ 有 |
| **独立卫浴** | ✅ 有 |
| **断电** | ✅ **24小时不断电** |
| **断网** | 外网全天可用 |
| **报修** | 设施免费报修 |

### 🚿 热水供应时间

| 时段 | 说明 |
|------|------|
| 早上 6:00 - 10:00 | 有热水 |
| 中午 12:00 - 14:00 | 有热水 |
| 下午 16:00 后 - 凌晨 00:30 | 有热水 |
| 其他时间 | ❌ 没热水 |

### ⚠️ 宿舍规则（官方+学长经验）

| 项目 | 规定 |
|------|------|
| 床帘 | 可挂但**不可全封闭**（需留透气） |
| 违禁电器 | 大功率煮锅、电热毯等**违禁** |
| 吹风机 | 可用，注意功率限制 |
| 查寝 | 基本不查 |
| 室友分配 | 床位随机分配，**不支持早到挑选** |
| 提前入住 | ❌ 不能提前入校，9月2-3日报到 |

### 🪑 空间

- 行李箱放得下
- 电竞椅偏大会占位置
- 宿舍楼下有自行车停放点

## 🔑 入住流程

1. 「知行理工」APP →「掌上迎新」查询宿舍楼栋和床位号
2. 报到当天凭录取通知书和身份证到楼栋前台登记
3. 领取寝室钥匙和空调遥控器
4. 20:00后到校联系辅导员

---

## ⚠️ 安全须知 & 防骗提醒

1. 宿舍禁止使用大功率电器
2. 进出随手关门锁窗，贵重物品入柜
3. 宿舍钥匙不外借
4. 禁止堵塞消防通道
5. ⚠️ **个人信息泄漏警告**：有新生反映录取后接到办卡推销电话！学校不会在进校前收任何费用，第一次缴费只有学费和住宿费！
6. 报到期间不轻信上门推销
