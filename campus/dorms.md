# 🛏️ 宿舍指南

> 你未来四年的小窝，提前了解一下～

---

## 📍 花溪校区

数智管理专业大一在**花溪校区**（巴南区红光大道69号）。

---

## 🏠 宿舍配置（整合小红书学长学姐真实经验）

### 基本设施

| 项目 | 详情 |
|------|------|
| **房型** | 四人间，上床下桌 |
| **空调** | ✅ 有，每间领取遥控器一个 |
| **独立卫浴** | ✅ 有 |
| **阳台** | 开放式阳台 |
| **隔音** | ⚠️ 个人感觉不太隔音 |

### 🚿 热水供应时间

| 时段 | 说明 |
|------|------|
| 早上 6:00 - 10:00 | 有热水 |
| 中午 12:00 - 14:00 | 有热水 |
| 下午 16:00 后 - 凌晨 00:30 | 有热水 |
| 其他时间 | ❌ 没热水 |

> 💡 每学期会发水卡，可以洗澡、接热水

### ⚡ 用电

- 电热毯可以用（冬天）
- 不允许大功率电器（电磁炉等）

### 🪑 空间

- 行李箱放得下
- 电竞椅偏大会占位置
- 床尺寸待确认（建议买床上用品前先量）

## 💻 宿舍网络（整合真实反馈）

| 运营商 | 评价 |
|--------|------|
| 中国电信 | ⭐⭐⭐ 相对稳定 |
| 中国移动 | ⭐⭐ 部分用户反映不佳 |
| 中国联通 | ⭐⭐⭐ 不打游戏够用 |

- **59元/月** 100M套餐（移动/电信统一价）
- 账号支持 **3台设备**同时在线
- ⚠️ 合同一般一年，未满一年注销可能算违约
- ⚠️ 换地方需要重新登录

## 🔑 入住流程

1. 「知行理工」APP →「掌上迎新」查询宿舍楼栋和床位号
2. 报到当天凭录取通知书和身份证到楼栋前台登记
3. 领取寝室钥匙和空调遥控器
4. 20:00后到校联系辅导员

---

## ⚠️ 安全须知 & 防骗提醒

1. 宿舍禁止使用大功率电器
2. 进出随手关门锁窗，贵重物品入柜
3. 宿舍钥匙不外借
4. 禁止堵塞消防通道
5. ⚠️ **个人信息泄漏警告**：有新生反映录取后接到办卡推销电话！学校不会在进校前收任何费用，第一次缴费只有学费和住宿费！
6. 报到期间不轻信上门推销
