# 📚 课程介绍

> 数智管理到底学什么？来看实际课程～

---

## 🎯 培养目标

数智管理 = **数据** + **智能** + **管理**，培养能用数据和 AI 工具解决实际商业问题的人才。

---

## 📋 主要课程体系

> 以下课程信息来源于重庆理工大学课程攻略共享计划（GitHub），具体以培养方案为准。

### 📖 通识必修课

| 课程 | 说明 |
|------|------|
| 高等数学 | 数学基础 |
| 线性代数 | 数据科学必备 |
| 概率论与数理统计 | 统计思维基础 |
| 大学英语 | 四六级 + 专业英语 |
| 大学物理 + 物理实验 | 自然科学基础 |
| 中国近代史 | 思政必修 |
| 思想道德与法治 | 思政必修 |
| 马克思主义基本原理 | 思政必修 |
| 毛泽东思想和中国特色社会主义理论体系概论 | 思政必修 |
| 习近平新时代中国特色社会主义思想概论 | 思政必修 |
| 创业基础 | 创新思维 |

### 💻 计算机与数据类

| 课程 | 说明 |
|------|------|
| 计算机科学概论 | 入门导引 |
| 程序设计基础 | C 语言入门 |
| Python 程序设计与数据分析 | ⭐ 核心技能 |
| 面向对象程序设计（Java） | 编程进阶 |
| 数据结构 | 算法基础 |
| 数据库系统概论 | SQL 必学 |
| 计算机网络 | 网络基础 |
| 智能数据分析程序设计 | 数据科学实战 |
| 数据可视化 | 把数据变好看 |

### 📊 管理类

| 课程 | 说明 |
|------|------|
| 管理学概论 | ⭐ 专业核心 |
| 软件工程 | 项目管理思维 |
| 数据与系统 | 信息系统基础 |
